## 🚀 Getting Started & Local Setup

The Dark Horizon landing page is lightweight and runs in any modern browser without heavy node dependencies or build chains.

### Option 1: Direct File Launch
Simply double-click `index.html` or open it with your preferred web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Apple Safari).

### Option 2: Live Server in VS Code
1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension (by Ritwick Dey).
3. Right-click on `index.html` and select **"Open with Live Server"**.
4. The site will automatically launch at `http://127.0.0.1:5500/`.

### Option 3: Python Built-In HTTP Server
If Python is installed on your system:
```bash
# For Python 3.x
python -m http.server 8080
```
Open your browser and navigate to `http://localhost:8080`.

### Option 4: Node.js (npx serve)
```bash
npx serve .
```
